Andesprit is an independent software studio from the Andes. We build productivity tools, games and open-source software, and create custom chatbots, LLM agents, automations and webpages around defined business workflows.

## Products

| Product | What it does |
| --- | --- |
| [Dictaria](https://dictaria.andesprit.com/) | Meeting Coach, live transcription and notes, with web access and official desktop downloads. Private source. Web; macOS 15+ Apple Silicon · stable; Windows x64 · preview. [Desktop downloads](https://github.com/Andesprit/Dictaria-Desktop/releases/latest). |
| [Smart Nutrition](https://smart-nutrition.andesprit.com/) | Explore food-label analysis and comparisons for nutritional choices. Private source. |
| [Study Buddy](https://study-buddy.andesprit.com/) | Turn study material into questions and review sessions. Private source. |
| [book-advisor](https://book-advisor.andesprit.com/) | Explore book suggestions from a shelf photo and your reading preferences. Private source. |
| [FairSplit](https://fair-split.andesprit.com/) | Calculate shared expenses in proportion to income. Private source. |
| [Day Conductor](https://dayconductor.andesprit.com/) | Connect goals, routines and daily plans in a planning workspace. Private source. |
| [Smart Pomodoro](https://smart-pomodoro.andesprit.com/) | A focus timer with work sessions and adaptive breaks. Private source. |
| [Chord Changes](https://chord-changes.andesprit.com/) | Track guitar chord-transition practice manually. Private source. |
| [Web Editor](https://webeditor.andesprit.com/) | Record your screen, camera or both, cut and frame the take, then export video or audio in the browser. Private source. Chrome, Edge and other Chromium browsers. The public editor provides manual editing. Separate agent-driven editing workflows are documented in the project repository. |

## Open Source and Public Code

| Project | What it does |
| --- | --- |
| [Flow Atelier](https://github.com/Andesprit/flow-atelier) | Compose agent and tool tasks into reproducible workflows, with review and human input along the way. Open source · Apache-2.0. macOS Apple Silicon · Linux · Windows. |
| [Quire Writer](https://github.com/Andesprit/quire-writer) | Write in Typst, LaTeX, Quarto or Markdown with your choice of AI agent, and review every agent edit. | [AnnoLabel](https://github.com/Andesprit/annolabel) | Validate and visually review agent-supplied image annotations, then export labels, boxes and polygons as COCO. Open source · MIT. Python 3.11–3.14 · macOS, Linux, Windows. |
