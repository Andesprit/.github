Andesprit is an independent software studio from the Andes. We build focused productivity products and open-source software, and create custom AI agents, automations, chatbots and web platforms for organizations of every size.

## Products

| Product | What it does |
|---|---|
| [Dictaria](https://dictaria.andesprit.com/) | Turns meetings into searchable transcripts, summaries, action items and grounded answers |
| [Smart Nutrition](https://smart-nutrition.andesprit.com/) | Scans packaged foods and shows how each option fits your nutrition goals |
| [Study Buddy](https://study-buddy.andesprit.com/) | Turns learning material into focused flashcards with spaced-repetition practice |
| [book-advisor](https://book-advisor.andesprit.com/) | Reads a photographed bookshelf and ranks the books available to you by your taste |
| [FairSplit](https://fair-split.andesprit.com/) | Divides shared expenses according to each person's income |
| [Day Conductor](https://dayconductor.andesprit.com/) | Connects long-term goals to weekly routines and today's work |
| [Smart Pomodoro](https://smart-pomodoro.andesprit.com/) | Combines an adaptive focus timer with a lightweight task workspace |
| [Chord Changes](https://chord-changes.andesprit.com/) | Isolates and measures the chord transitions inside real songs |
